# Bundled font licenses

The Android application bundles the following fonts so Traditional Chinese
text changes together with the selected app font instead of falling back to
the same device font:

- Huninn Regular — https://github.com/google/fonts/tree/main/ofl/huninn
- Noto Sans TC — https://github.com/google/fonts/tree/main/ofl/notosanstc
- Noto Serif TC — https://github.com/google/fonts/tree/main/ofl/notoseriftc
- Iansui Regular — https://github.com/google/fonts/tree/main/ofl/iansui
- Noto Sans Mono CJK TC — https://github.com/notofonts/noto-cjk/tree/main/Sans/Mono
- Roboto — https://github.com/google/fonts/tree/main/ofl/roboto
- Inter — https://github.com/google/fonts/tree/main/ofl/inter
- Nunito — https://github.com/google/fonts/tree/main/ofl/nunito
- Playfair Display — https://github.com/google/fonts/tree/main/ofl/playfairdisplay
- Caveat — https://github.com/google/fonts/tree/main/ofl/caveat
- JetBrains Mono — https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

These font files are distributed under the SIL Open Font License 1.1. The
license text is included in `OFL-1.1.txt` in this directory.
