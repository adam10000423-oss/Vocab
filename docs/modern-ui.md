# 3.1 UI 實作清單

## 共用規格

- 主題：亮色、暗色、跟隨系統；不提供自行調整文字或資料夾顏色。
- 背景：亮色 `#F6F7F9`；暗色 `#0F1115`。
- 一般表面：亮色 `#FFFFFF`；暗色 `#191C22`。
- 輸入表面：亮色 `#EDF0F4`；暗色 `#262A32`。
- 主色：亮色 `#245FE5`；暗色 `#82AAFF`。
- 內容區塊圓角 20dp；輸入框、主要操作 16dp；搜尋框 28dp；視窗 28dp。
- 按鈕最小高度 48dp；選擇題最小高度 62dp；欄位保留系統字級與無障礙縮放。
- 除透明毛玻璃導航列外，不添加漸層／裝飾性陰影；錯誤提示保留語意色。

## 驗證範圍

`ModernScreensTest` 使用實際文法主頁、文法庫、文法編輯和長資料夾選擇清單，檢查次級操作、套用、空白處滑動和畫面輸出。`GreetingScreenshotTest` 驗證主頁限定的模式切換與翻卡左右滑評分、沒有評分按鈕。

這些為 Robolectric 測試與畫面檢查，不等同實體手機上的掃描器、背景朗讀或系統浮窗權限測試；正式發布仍使用既有簽章與未縮減的掃描建置設定。
